前日ニュース外部収集基盤 v0.2.1 更新手順
対象: https://github.com/NAKKENth/daily-news-collector

現在のdata/（SQLite・収集結果）は削除しない。実行中のActionsがない状態で更新する。

1. ZIPを展開して news-intake-kit を開く。
   GitHubのルートでAdd file → Upload filesから次の直下ファイルを選んでアップロードし、Commit changes。
   collector.py, quality.py, catalog_v021.py, sources.json, sources_catalog.csv,
   README.md, VALIDATION.md, UPDATE_v0.2.1.txt, タスク接続用_追記文.txt
   その他の旧ファイルは変更不要。旧UPDATE_v0.2.txtも残して構わない。
   https://github.com/NAKKENth/daily-news-collector/upload/main
2. .github/workflows/collect.yml をZIP内の同じファイルの内容に全文差し替えてコミット。
   https://github.com/NAKKENth/daily-news-collector/edit/main/.github/workflows/collect.yml
3. GitHubのtestsフォルダに移動し、ZIPのtests/test_collector.py（上書き）とtest_v021.py（追加）をアップロード。
   既存test_v02.pyは維持。ルートに置かない。
   https://github.com/NAKKENth/daily-news-collector/tree/main/tests
4. Actionsの個別ページ → Run workflow → main / all → Run workflow。
   https://github.com/NAKKENth/daily-news-collector/actions/workflows/collect.yml
   既存ジョブのRe-runではなく新規実行を使用。
5. data/latest/manifest.json と README.md、4分野JSONを確認。
   collector_version が 0.2.1 になっていることを確認。
   search_deferred / pending_search_total は失敗・未取得の繰越であり、成功ではない。
   https://github.com/NAKKENth/daily-news-collector/tree/main/data/latest
6. 次回の定期実行（または google_retry_after_utc を過ぎてから retry）で繰越の減少を確認。
   429中に連続手動実行しない。次回基準保存の一覧/ページは新着と判定しない。

既存4つのChatGPTタスクは検証完了まで変更しない。緑のチェックだけで合格とはしない。
