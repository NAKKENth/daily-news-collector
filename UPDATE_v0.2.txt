既存 GitHub リポジトリへの更新手順
対象: https://github.com/NAKKENth/daily-news-collector

既存リポジトリの data/（SQLite・収集結果）はそのまま残す。
実行中のActionsがないことを確認してから更新する。

【GitHub Webで更新する場合】
1. ZIPを展開して news-intake-kit を開く。
2. リポジトリの Add file → Upload files から、フォルダ直下のファイルだけをアップロードする。
   collector.py, quality.py, catalog_upgrade.py, configure_sources.py,
   sources.json, sources_catalog.csv, README.md, AUTOMATION_LINKS.md,
   タスク接続用_追記文.txt, UPDATE_v0.2.txt, VALIDATION.md
   既存 requirements.txt / BAT / .gitignore は変更不要。
   同名ファイルは更新する。Commit changes。
3. .github/workflows/collect.yml の編集ページを開き、ZIP内の同じファイルの全内容へ差し替える。
   https://github.com/NAKKENth/daily-news-collector/edit/main/.github/workflows/collect.yml
   Commit changes。
4. tests フォルダを開き、そのフォルダ内で Add file → Upload files を選び、
   tests/test_collector.py と tests/test_v02.py の2ファイルをアップロード。
   https://github.com/NAKKENth/daily-news-collector/tree/main/tests
   ルートに置かない。Commit changes。
5. Actions → News candidate collection → Run workflow → all を選択して実行。
6. 終了したらmanifest.jsonとdata/latest/README.mdを確認。
   https://github.com/NAKKENth/daily-news-collector/tree/main/data/latest
   2回目のall/coreで一覧とページ変更監視を確認する。

注意: GitHub Actionsが緑色でも、取得状態がpartialなら全ソース成功ではない。
既存4つのChatGPTタスクはまだ変更しない。
